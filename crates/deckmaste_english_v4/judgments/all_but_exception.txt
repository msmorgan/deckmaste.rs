# Exceptive "all but N" as a determiner phrase (all + but-PP) in prenominal and partitive NPs
+DeterminerPhrase all but 1 => PrepositionPhrase "but 1"
+DeterminerPhrase all but one => PrepositionPhrase "but one"
+DeterminerPhrase all but that many => PrepositionPhrase "but that many"
+PrepositionPhrase but 1 => Amount "1" as Complement of but
+NounPhrase all but 1 life => DeterminerPhrase "all but 1" as Determiner of life
+NounPhrase all but one +1/+1 counter => DeterminerPhrase "all but one" as Determiner of "+1/+1 counter"
+NounPhrase all but that many permanents => DeterminerPhrase "all but that many" as Determiner of permanent
+NounPhrase all but 1 of that damage => DeterminerPhrase "all but 1"
+NounPhrase all but one of them => DeterminerPhrase "all but one"
