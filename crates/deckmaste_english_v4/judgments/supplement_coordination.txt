# A Supplement is a complete NP, not the singular-count nominal tail of a shared determiner (CGEL Ch. 5 §8.5, pp. 409–410; Ch. 15 §3.1, p. 1323).
# These deferred shared-determiner coordinations must be read in their entirety as the predicative Complement, never counted as coverage through a detached tail.

# The relative clause must contain all three alternatives. A separate imperative is grammatical clause coordination but not the intended analysis of these deferred units.
+ <card=Hearth Elemental> This spell costs {X} less to cast, where X is the number of cards in your graveyard that are instant cards, sorcery cards, and/or have an Adventure. => RelativeClause "that are instant cards, sorcery cards, and/or have an Adventure"
+ <card=Frantic Firebolt> Frantic Firebolt deals X damage to target creature, where X is 2 plus the number of cards in your graveyard that are instant cards, sorcery cards, and/or have an Adventure. => RelativeClause "that are instant cards, sorcery cards, and/or have an Adventure"
# A complete NP coordination can still supplement a Clause; both plural count heads and independently determined conjuncts are permitted.
+ <card=Minsc, Beloved Ranger> Create Boo, Hamster creature tokens and Bird creature tokens. => NounPhrase "Boo" as Object of create; NounPhrase "Hamster creature tokens and Bird creature tokens"
+ <card=Minsc, Beloved Ranger> Create Boo, a Hamster creature token and a Bird creature token. => NounPhrase "Boo" as Object of create; NounPhrase "a Hamster creature token and a Bird creature token"
