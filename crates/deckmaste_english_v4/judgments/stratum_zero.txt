# Card-frame syntax, keyword parameter frames, and outer spines over seed payloads.
+ Legendary Artifact Creature — Golem => TypeLine "Legendary Artifact Creature — Golem"
+ Basic Snow Land — Island => TypeLine "Basic Snow Land — Island"
+ Flying, vigilance, trample => KeywordParameters "Flying"; KeywordParameters "vigilance"; KeywordParameters "trample"
+ Vigilance; horsemanship (This creature can't be blocked except by creatures with horsemanship.) => KeywordParameters "Vigilance"; KeywordParameters "horsemanship"; readings 1
+ Ward {2}
+ Equip—Sacrifice a creature.
# A standalone keyword line is unpunctuated; an imperative sentence ends in a period (oracle-style-guide §3, "Periods").
+ Equip {2} => KeywordParameters "Equip {2}"; !Clause "Equip {2}"; readings 1
+ Choose a Background => KeywordParameters "Choose a Background"; !Clause "Choose a Background"; readings 1
+ Cascade => KeywordParameters "Cascade"; !Clause "Cascade"; readings 1
+ Equip legendary creature {1} => Quality "legendary creature"
+ Enchant creature without flying => PrepositionPhrase "without flying" as Modifier of creature
+ Swampwalk => KeywordParameters "Swampwalk"
+ Nonbasic landwalk => KeywordParameters "Nonbasic landwalk"; Quality "Nonbasic land"
+ Basic landcycling {1}{W} => KeywordParameters "Basic landcycling {1}{W}"; Quality "Basic land"; !Quality "Basic landcycling {1}{W}"
+ Landfall — Destroy a creature. => NounPhrase "a creature" as Object of destroy
+ Uncharted marvel — Destroy a creature. => NounPhrase "a creature" as Object of destroy
+ {2}{U}, {T}: Destroy a creature. => Cost "{2}{U}, {T}"; NounPhrase "a creature" as Object of destroy
+ {Q}, {E}{E}: Destroy a creature. => Cost "{Q}, {E}{E}"
+ [+2]: Destroy a creature. => ActivationCost "[+2]"
+ [−2]: Destroy a creature. => ActivationCost "[−2]"
+ [0]: Destroy a creature. => ActivationCost "[0]"
+ Choose one — => NounPhrase "one" as Object of choose
+ Choose one or both — => NounPhrase "one or both" as Object of choose
+ • Destroy a creature. => NounPhrase "a creature" as Object of destroy
+ + {2}{G} — Destroy a creature. => Cost "{2}{G}"; NounPhrase "a creature" as Object of destroy
+ • Thunder — {2}{G} — Destroy a creature. => Cost "{2}{G}"; NounPhrase "a creature" as Object of destroy
+ {P}{P} — Destroy a creature. => NounPhrase "a creature" as Object of destroy
+ I, II — Flying => KeywordParameters "Flying"
+ III — Uncharted marvel — Flying => KeywordParameters "Flying"
+ Artifact landcycling {2} => KeywordParameters "Artifact landcycling {2}"
+ I, II — Choose one — => NounPhrase "one" as Object of choose
+ LEVEL 1-3
+ LEVEL 4+
+ {W}{U}: Level 2
+ Prototype {1}{B} — 1/1 => Measure "1/1"
+ −2: Destroy a creature. => ActivationCost "−2"
+ +2: Destroy a creature. => ActivationCost "+2"
+ 0: Destroy a creature. => ActivationCost "0"
+ Choose one or more — => NounPhrase "one or more" as Object of choose
* Enchant two creature

+ Escape—Sacrifice a creature.
# A keyword line item has its parameters: the bare mention *Dash* is no keyword line before a sentence.
+ <card=Warbringer> Dash costs you pay cost {2} less. => Nominal "Dash costs"; !KeywordList "Dash"; !KeywordPhrase "Dash costs you pay cost {2} less"
