# workbench-event-disjunction-tail

Two remainders from trigger-2 (done 2026-08-27) whose named owner
(workbench-event-algebra) is already closed, re-homed here:

- **The general event disjunction.** `AltEvent` (n-ary events under one
  trigger word) survives; a general disjunction would RETIRE it rather than
  sit beside it (the umbrella's coupling). The decidable groundwork now
  exists: `sameBindings`/`armsAgree`/`sharedCtx` carry the common-announcement
  read at both header seats (`headerCtx`, `joinedCtx`). ~100 coordinated
  headers whose arms disagree stay refused and counted at
  `badAltHeaderMixedReadback`/`badThreeArmHeaderReadback` — a general
  disjunction is what would move them, if anything rules-grounded can.
- **The step-inside-a-keyword-action event.** The Temporal Anchor triggers on
  "you choose to put one or more cards on the bottom of your library" — a step
  INSIDE the scry that no event row names. `eventUnderwayOk` (trigger-2) knows
  which actions have steps; an event naming a step is a different ask. 1
  supported card; wait for a second carrier or a rules argument before
  building.
