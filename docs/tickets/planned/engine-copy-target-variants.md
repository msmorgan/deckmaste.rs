The effect-driven copy-targeting variants on top of the core copy machinery.
[CR#707.10d] "for each player or object it could target" (Zada, Hedron
Grinder / Mirrorwing Dragon): enumerate every object legal for EVERY target
instance, mint one copy per, each copy's every slot set to that object,
copies stacked in their controller's chosen order. [CR#707.10e]
effect-designated new target (Frontline Heroism): the copy is created with a
FORCED target; if that object isn't legal for every target instance, no copy
is created at all.
