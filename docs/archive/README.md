# Archived Documentation

This directory holds superseded architectural decision records and historical
workbench snapshots retained for provenance only.

- **Not current authority:** Do not consult files in `docs/archive/` when
  designing, implementing, or reviewing current code. Read
  [`docs/decisions/`](../decisions/README.md) and [`docs/contexts/`](../contexts/)
  instead.
- **Ignored by search:** `docs/archive/.ignore` (`*`, `!README.md`) excludes
  archived files from `rg` and `fd` by default, and `cite-config.json` excludes
  `docs/archive/` from active CR citation checks.
